Supabase integration checklist

  • Connect Supabase URL and anon key in frontend environment/config.
  • Create server-side endpoints for account creation and privileged actions.
  • Enable and test RLS policies for admin, distributor, and retailer roles.
  • Verify payment provider webhooks before creating commission entries.
  • Use private Storage buckets for Aadhaar, PAN, bank passbook and photos.
  • Use the Supabase connection panel above to load configured tables. Check column names/RLS if a table operation fails.
