04 · Deploy your HTML website

Recommended: Cloudflare Pages

1. Put index.html, CSS and JavaScript in a folder.

2. Open the Cloudflare dashboard → Workers & Pages → create a Pages project.

3. Upload the folder or connect your Git repository; no build command is needed for plain HTML.

4. Deploy, then connect your custom domain and HTTPS.

Shared hosting: upload your frontend files into public_html using hPanel or cPanel; enable SSL and connect DNS.

Rented VPS: install Ubuntu LTS, Nginx and a TLS certificate; upload files to the web root, configure DNS, restrict firewall to required ports, patch regularly and set up backups.

Keep payment secrets and Supabase service-role keys on the backend, never in HTML or browser JavaScript. Compile Tailwind for production rather than using its browser development CDN.
